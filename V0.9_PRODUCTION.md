# MboaScribe v0.9 — Production workflow foundation

## Added
- Separate worker application signup at `/{locale}/signup/worker`.
- Worker application review/approval queue.
- Worker profile/capability schema foundation.
- Task submission lifecycle: assigned → accepted → in progress → submitted.
- Submission/review persistence foundation.
- Privileged audit log.
- SUPERADMIN Admin invitation via Supabase Admin API.
- Localized portal sidebar for EN/FR/ES.
- Portal spacing/rhythm cleanup and Next.js smooth-scroll marker.

## Required environment
`SUPABASE_SERVICE_ROLE_KEY` (server only; never NEXT_PUBLIC) for SUPERADMIN account invitations.
`NEXT_PUBLIC_SITE_URL` should be your canonical app URL in production and localhost in development as appropriate.

## Migration
Run `npx drizzle-kit check`, then `npx drizzle-kit generate`. Review the generated migration before `npx drizzle-kit migrate`.
Then rerun `drizzle/seed-rbac.sql`.

## Security
Worker signup creates a PENDING application only. It never self-assigns roles. Approval creates the worker profile and currently grants TRANSLATOR as the initial workforce role; capability-specific role selection is the next refinement and should be chosen by Admin during approval.
SUPERADMIN remains protected from the general role form.
