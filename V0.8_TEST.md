# MboaScribe v0.8 — Role Portals & Platform Administration

No schema migration is required from v0.7. Re-run `drizzle/seed-rbac.sql` so existing ADMIN/OPERATIONS/workforce grants are current.

## Acceptance checks
1. SUPERADMIN dashboard shows platform KPIs and links to Orders, Task Queue, Customers, Payments, Users & Roles, Roles & Permissions, Task Types, Settings.
2. A user without a platform role sees the customer portal only.
3. A TRANSLATOR/TRANSCRIBER/REVIEWER sees My Tasks, not platform administration.
4. OPERATIONS sees operational pages but not protected platform governance.
5. ADMIN sees operational/user administration based on permissions.
6. Direct URL access is guarded server-side; hidden navigation is not the security boundary.
7. Users & Roles can add/remove non-SUPERADMIN roles. SUPERADMIN cannot be assigned through the general form.
8. Customer Files and Payments pages query only orders created by that profile.
