# MboaScribe v0.7 acceptance test

No schema migration is required beyond the already-applied v0.6 task-domain migration.

1. `npm install`
2. `npm run build`
3. `npm run dev`
4. Log in as the bootstrapped SUPERADMIN.
5. Create a Translation order from `/en/dashboard/new-order`.
6. Confirm the order detail page shows the generated work plan.
7. Upload a supported document. The browser uploads directly to private R2, then `/api/uploads/confirm` verifies the object exists before marking the DB row `UPLOADED`.
8. Open Operations → Task queue and assign the TRANSLATION task.
9. The assignee should see the task under My tasks when logged in.

## R2 CORS
Direct browser PUT uploads require the R2 bucket CORS policy to allow the local and deployed MboaScribe origins, `PUT`, and the `Content-Type` header. Keep the bucket private.
